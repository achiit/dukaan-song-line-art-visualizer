Export, Android and troubleshooting

This page is a live preview, not an MP4.

Easiest: load audio, tap Clean view, Fullscreen, start your screen recorder (Android: Quick Settings → Screen record, with device audio on Android 14+), then Play. Trim afterwards.

Exact MP4 (PC): put render.js and this page in one folder, run npm i puppeteer, install ffmpeg, then:

node render.js --audio song.mp3 --lrc lyrics.lrc --out alfaaz-portrait.mp4
node render.js --audio song.mp3 --lrc lyrics.lrc --land --out alfaaz-16x9.mp4

Troubleshooting: choppy on Android: close other tabs, switch off amplitude bars and glow. No sound: tap Play once, then check volume. Out of sync: change the start point or nudge. Long analysis on a huge file: use a 5 to 10 minute clip.
